💻 Coding Lab

A few programming problems I've explored while learning.

01

Palindrome Number

Check whether a number reads the same forward and backward.

My Approach

Reverse the number using a loop and compare it with the original number.

Language: C++ Time: O(log n)
02

Reverse a Number

Reverse the digits of a given integer using basic arithmetic operations.

My Approach

Extract the last digit using modulo and build the reversed number.

Language: C++ Time: O(log n)
03

Binary Search

Find an element efficiently in a sorted array.

My Approach

Repeatedly divide the search space into two halves.

Language: C++ Time: O(log n)
04

Selection Sort

Sort an array by repeatedly selecting the smallest element.

My Approach

Find the minimum element and place it at the correct position.

Language: C++ Time: O(n²)
